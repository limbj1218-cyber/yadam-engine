1. 초기 화면 — 이미지 스튜디오

프로그램을 실행하면 이미지 스튜디오 탭이 기본으로 표시됩니다. 좌측 패널에서 데이터를 입력하고 생성 옵션을 설정합니다.

영역설명
엑셀 시나리오 업로드시나리오가 담긴 .xlsx 파일을 업로드합니다
기존 작업 동기화이전에 작업하던 프로젝트를 불러옵니다
AI 모델이미지 생성에 사용할 AI 모델을 선택합니다 (예: Nano Banana 2)
이미지 비율생성될 이미지의 비율을 설정합니다 (16:9, 1:1 등)
동시 생성한 번에 동시에 생성할 이미지 수
생성 간격이미지 생성 사이의 대기 시간 (초)
자동 개별 다운로드생성 완료 시 자동으로 개별 파일로 저장 (토글 ON/OFF)
하단의 캐릭터 영문 라이브러리와 SMART SYNC 버튼은 시나리오 업로드 후 캐릭터 매칭에 사용됩니다. 4단계에서 자세히 설명합니다.

2. 엑셀 시나리오 업로드

엑셀 시나리오 업로드 버튼을 클릭하여 준비된 .xlsx 파일을 업로드합니다.

업로드가 완료되면 두 가지 변화가 생깁니다:

  1. 상단에 턴어라운드 시트 생성기 탭이 자동으로 추가됩니다.
  2. 메인 영역에 작업 대기열이 표시되며, 영문 매칭 및 스마트 싱크가 적용된 시나리오 목록을 확인할 수 있습니다.
다음 단계: 새로 생긴 턴어라운드 시트 생성기 탭을 클릭하여 캐릭터 턴어라운드 이미지를 먼저 생성합니다.

3. 턴어라운드 시트 생성

턴어라운드 시트 생성기 탭으로 이동하여 캐릭터별 다각도 레퍼런스 이미지를 생성합니다.

  1. 프롬프트 TXT 업로드 버튼을 클릭하여 캐릭터별 프롬프트가 담긴 .txt 파일을 업로드합니다.
  2. 좌측에서 AI 모델, 이미지 비율, 동시 생성 수, 생성 간격을 설정합니다.
  3. 하단의 일괄 생성 시작 버튼을 클릭합니다.

생성 결과 확인

  • 각 캐릭터별로 다양한 각도의 턴어라운드 이미지가 자동 생성됩니다.
  • 카드에는 캐릭터 이름, 나이, 의상 정보와 프롬프트가 표시됩니다.
  • 하단 로그에서 생성 진행 상황을 실시간으로 확인할 수 있습니다.
  • 각 카드의 다시 생성 버튼으로 개별 재생성이 가능합니다.
생성이 완료된 턴어라운드 이미지는 자동으로 이미지 스튜디오의 캐릭터 라이브러리에 등록됩니다. 별도의 수동 작업이 필요하지 않습니다.

4. 스마트 싱크 — 캐릭터 매칭

다시 이미지 스튜디오 탭으로 돌아와 캐릭터 라이브러리를 확인합니다.

캐릭터 영문 라이브러리 상태

시나리오에 등장하는 캐릭터가 목록으로 표시되며, 각 캐릭터의 매칭 상태를 확인할 수 있습니다:

상태의미
MISSING영문 프롬프트가 아직 매칭되지 않았습니다
FOUND IN TURNAROUND턴어라운드 시트에서 캐릭터가 자동 발견되었습니다

직접 영입하기 버튼으로 캐릭터를 수동 추가할 수도 있습니다.

중요: 반드시 SMART SYNC 버튼을 클릭해야 캐릭터 라이브러리의 영문 프롬프트가 이미지 생성 시 실제로 적용됩니다.
싱크하지 않으면 캐릭터 정보 없이 이미지가 생성됩니다.

5. 이미지 스튜디오 일괄 생성

스마트 싱크 완료 후, 이미지 스튜디오에서 최종 야담용 이미지를 생성합니다.

생성 전 확인사항




모든 준비가 되었다면, 하단의 일괄 생성 버튼을 클릭하세요. 작업 대기열의 시나리오가 순차적으로 처리되며, 각 장면에 맞는 야담용 이미지가 자동 생성됩니다.

압축 다운로드 버튼으로 생성된 전체 이미지를 ZIP 파일로 일괄 다운로드할 수 있습니다.
